# 제일종합학원 로컬 콘셉트 사이트

화이트 배경과 코발트 블루, AI 가상 강사진 6명, 스크롤에 맞춰 전환되는 7개 장면을 갖춘 홈페이지입니다.

## 보기
1. 이 폴더의 **미리보기_시작.cmd**를 더블 클릭합니다.
2. 브라우저에서 **http://127.0.0.1:4173**을 엽니다.
3. 종료할 때 **미리보기_종료.cmd**를 더블 클릭합니다.

이 컴퓨터에서만 실행됩니다. 처음부터 프로그램을 설치할 필요 없이 현재 Codex의 Node.js 런타임을 사용합니다. 다른 컴퓨터로 옮길 때는 Node.js가 필요합니다. 포트 4173에서 다른 서비스가 실행 중이면 자동 종료하지 않습니다.

## 구성
- dist/index.html: 공통 문서, 메뉴, 하단, 모달
- dist/styles.css: 디자인, 모바일 화면, 동작 줄이기
- dist/views.js: 메인과 상세 5개 페이지
- dist/app.js: 스크롤, 이동, 선택, 상담 체험
- dist/data.js: 강사진·교육 과정·소식 예시
- dist/assets: SVG 로고, WebP 인물 6명, GSAP, 한글 글꼴
- server.mjs: 로컬 읽기 전용 서버
- preview.ps1 및 실행 파일 2개: 시작과 종료
- test.mjs, test-results.json: 검증 코드와 결과
- image-manifest.json: AI 이미지 생성 기록

코드를 직접 수정하실 필요는 없습니다. 변경할 과목, 문구, 디자인을 채팅으로 요청하면 됩니다.

상담 체험은 학년 → 과목 → 학습 목표 순서이며 개인정보를 입력하거나 외부로 전송하지 않습니다. 현재는 모든 학원 정보와 강사진이 가상의 예시입니다.

소스 저장소: [hyun-pixel/Homepage_academy](https://github.com/hyun-pixel/Homepage_academy). GitHub에 소스를 올리는 작업과 홈페이지를 인터넷에 배포하는 작업은 별개입니다.


## 주요 소식 팝업

홈에서 자동으로 열리는 3종 팝업을 추가했습니다. 제일 소식 버튼으로 다시 열고, 각 제목이나 이전·다음을 눌러 내용을 전환할 수 있습니다. 오늘 하루 보지 않기를 체크하고 닫으면 한국 시간 자정까지 자동 표시를 숨깁니다. 브라우저에는 날짜만 저장합니다. 합격 문구는 사용자가 요청한 임의의 작성 내용이므로 실제 운영 전 확인된 자료로 교체해야 합니다.

## Node.js로 실행하기

Node.js가 설치된 컴퓨터에서는 프로젝트 폴더에서 npm start를 실행한 뒤 http://127.0.0.1:4173 을 열면 됩니다. 미리보기가 실행 중인 상태에서 npm run check를 실행하면 자동 검증을 진행합니다. 별도 패키지 설치나 환경변수 설정은 필요하지 않습니다.

제작 문서는 docs 폴더에 함께 보관합니다.
