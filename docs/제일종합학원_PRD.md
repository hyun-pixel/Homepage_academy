## 도입부와 움직임

1. 국어 인물이 첫 화면에 등장. 큰 과목명, 이름, 짧은 교육 메시지 표시.
2. 기본 스크롤에 맞춰 국어 → 영어 → 수학 → 사회 → 과학 → 한국사로 교체.
3. 인물의 위치·크기·투명도와 과목명의 움직임을 연결. 스크롤을 멈추거나 역방향으로 움직여도 자연스럽게 반응.
4. 여섯 인물이 모인 뒤 로고와 대표 문구 등장.
5. 마지막 장면을 지나면 일반 본문 스크롤로 연결.

도입부는 고정 장면으로 구성하되 스크롤을 강제로 다음 장면에 끌어가지 않는다. 과목별 장면 이동 기능을 제공한다. 메뉴와 버튼은 처음부터 사용할 수 있다. 모바일에서도 이름과 주요 문구, 버튼이 잘리지 않게 한다.

본문에서는 스크롤 진입, 버튼·카드 반응, 페이지 전환에 움직임을 적용한다. 정보를 읽는 동안 내용이 계속 움직이지 않게 한다. 동작 줄이기 설정에서는 고정 연출을 해제하고 모든 인물을 읽을 수 있는 정적 구성을 제공한다.

## 디자인 기준

- 내부 기준: 디자인 다양성 8/10, 도입부 움직임 9/10, 본문 움직임 6/10, 정보 밀도 4/10.
- 키보드 조작, 보이는 포커스, 터치 영역, 충분한 명암 대비를 유지.

## 교육 과정과 상담 규칙

교육 과정은 3학년 × 6과목의 예시 데이터로 구성한다. 기본은 고1·국어이며 유효한 URL 학년·과목 값이 있으면 해당 선택으로 열린다. 선택에 맞춰 과정 설명, 강사, 내신·수능 소개가 함께 변경된다.

상담 체험은 학년 1개, 관심 과목 1개, 목표 1개를 선택한다. 목표는 내신 집중 / 수능 준비 / 내신·수능 균형이다. 필수 선택 없이 다음 단계로 갈 수 없으며 안내를 표시한다. 이전 단계로 돌아가면 선택을 유지하고 다시 시작하면 초기화한다.

결과는 선택한 학년·과목·목표에 연결된 예시 과정과 학습 방향이다. 전문 상담이나 AI 진단으로 표현하지 않는다. 외부 전송·실제 접수·개인정보 저장이 없으며, 체험 결과임을 명시한다. 모달은 Escape로 닫을 수 있고 시작 버튼으로 포커스가 돌아간다.
