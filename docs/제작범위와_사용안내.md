# 제일종합학원 제작 범위와 사용 안내

인터뷰를 마친 뒤 2026년 10월 3일 기준으로 정리한 첫 제작 범위입니다.

## 제작 내용

- 화이트·네이비·코발트 블루 브랜드와 신규 SVG 로고.
- 20대~50대 한국인 성인 AI 프로필 6장.
- 선생님 6명과 로고로 이어지는 7장면 스크롤 연출. 모바일에서도 유지.
- 메인과 학원 소개·교육 과정·강사진·학습 관리·학원 소식, 총 6페이지.
- 학년·과목 선택형 교육 과정, 프로필과 소식 상세 보기.
- 학년·과목·목표를 선택하는 상담 체험과 추천 결과.
- 메뉴와 페이지 전환, 반응형 화면, 키보드 조작, 동작 줄이기 대응.

대표 문구는 **너의 가능성을, 제일 높이.**입니다. 메인 본문은 간결한 정보 요약과 상세 페이지 연결로 구성합니다.

## 범위 밖의 항목

실제 상담 접수, 개인정보 저장, 회원가입, 관리자, 결제, 데이터베이스, 외부 API, 도메인, 인터넷 게시는 포함하지 않습니다. 인물과 내용은 가상 설정입니다.

## 실행 방법

제작 완료 시 Codex 옆 브라우저에 로컬 미리보기를 열어드립니다.

나중에 다시 보려면 **jeil-academy 폴더의 미리보기_시작.cmd를 실행**하고 브라우저에서 **http://127.0.0.1:4173**을 여세요. 서버를 종료하려면 같은 폴더의 **미리보기_종료.cmd**를 실행하세요. 이 주소는 이 컴퓨터에서 보는 미리보기 주소입니다.

## 확인 순서

1. 메인에서 스크롤하며 여섯 선생님과 마지막 로고를 확인.
2. ‘본문 보기’와 과목 장면 버튼 사용.
3. 상단 메뉴에서 상세 페이지 이동.
4. 교육 과정에서 학년·과목 변경.
5. 강사진·소식 상세 보기.
6. 상담 체험에서 이전·다음·결과·다시 시작.
7. 브라우저 폭을 줄여 모바일 메뉴와 세로 배치 확인.
